# E-Commerce Sales Performance Dashboard

## Project Overview

This project uses Power BI to explore the Sample Superstore dataset and
present key sales and profitability insights in an interactive
dashboard.

## Objectives

-   Monitor overall sales, profit, orders, customers, quantity, profit
    margin, and average order value.
-   Compare sales and profit across product categories and regions.
-   Explore sales performance by customer segment.
-   Identify the top 10 products by sales.
-   Examine monthly sales trends over time.
-   Interactively filter the dashboard by region and customer segment.

## Tools Used

-   Microsoft Power BI Desktop
-   DAX (Data Analysis Expressions)
-   Microsoft Excel (`.xlsx`) for the source dataset

## Dataset

**Sample - Superstore.xlsx**

The Excel workbook included in this repository is the source dataset
used for this dashboard.

## Key Measures

-   Total Sales
-   Total Profit
-   Total Orders
-   Total Customers
-   Total Quantity
-   Profit Margin %
-   Average Order Value

## Dashboard Features

-   KPI cards for the main business metrics.
-   Monthly sales trend line chart.
-   Sales and profit analysis by category.
-   Sales and profit analysis by region.
-   Sales by customer segment.
-   Top 10 products ranked by sales.
-   Region and customer segment slicers for interactive filtering.

## How to Use

1.  Download or clone this repository.
2.  Open `E-Commerce_Sales_Performance_Dashboard.pbix` using Power BI
    Desktop.
3.  If Power BI requests the source file location, point it to
    `Sample - Superstore.xlsx`.
4.  Use the Region and Customer Segment slicers to explore the report.
